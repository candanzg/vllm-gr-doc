# H20-3e 离线 Beam Search 时延对比

单卡运行 OneRec-1.7B（BF16），固定生成 3 个 token。时延为处理整批请求的端到端墙钟时间，单位 ms。每点 48 个计时批次（3 轮 × 16 批），预热不计入。逐配置表展示 p50，源文件另含 mean、p90 和 p99。

U 为不启用受限表，C 为启用受限生成。按模式、输入 token 数、beam 宽度与 batch 大小逐点匹配，以 vllm-gr（本项目）为基准。时延比 = 竞品 p50 ÷ vllm-gr p50，大于 1 表示 vllm-gr 时延更低。

## 同配置汇总

| 模式 | 竞品 | 配对点数 | 时延比中位数 | 时延比范围 | vllm-gr 更快 / 持平 / 更慢 |
|---|---|---:|---:|---:|---:|
| U | SID-GR | 168 | 1.052× | 1.001–1.089× | 168 / 0 / 0 |
| U | SGLang | 168 | 2.104× | 1.225–5.598× | 168 / 0 / 0 |
| U | vLLM | 28 | 125.366× | 27.553–531.467× | 28 / 0 / 0 |
| C | SID-GR | 168 | 1.039× | 1.014–1.116× | 168 / 0 / 0 |

- SID-GR 是时延最接近 vllm-gr 的竞品，两种模式均覆盖 168 个同配置测点。下表保留各配置的差异。
- vLLM 仅测 U 模式的 batch=1、beam=32/64/128/256，共 28 点。由于大负载下运行耗时过长，测试止于这 28 点。表中「—」表示未测，汇总只使用实测交集。
- C 模式使用各后端的受限生成实现。vllm-gr 使用受限表，SID-GR 使用 SID 词表窗口和 trie 掩码。实验检查了输出结构，推荐精度未测。
- C 模式中，vllm-gr 的 8192 和 10240 token 配置来自独立补跑。SID-GR 的 10240 token、batch=4/8 共 12 点来自独立补跑。
